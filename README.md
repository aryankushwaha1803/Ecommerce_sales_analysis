
# 🛒 E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to discover meaningful business insights, understand sales performance, identify profitable product categories, and explore customer purchasing patterns.

The project uses SQL, Python, Power BI, and Tableau to perform data analysis and create interactive visualizations that support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand sales trends and customer purchasing patterns.
- Evaluate regional and segment-wise performance.
- Create interactive dashboards to communicate business insights.
- Practice real-world data analytics workflows.

## 📊 Project Workflow

1. **Data Preparation:** Load and inspect the e-commerce dataset.
2. **SQL Analysis:** Write queries to investigate sales, profit, products, and regional performance.
3. **Python Analysis:** Explore the data using Pandas, NumPy, and Plotly.
4. **Power BI Dashboard:** Present key performance indicators and business trends.
5. **Tableau Dashboard:** Build an interactive visualization for exploring sales insights.
6. **Business Insights:** Summarize findings that can support business decisions.
